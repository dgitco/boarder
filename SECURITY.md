# Security

Please report vulnerabilities privately through GitHub: on this repository, open **Security → Report a
vulnerability**. Don't open a public issue or pull request for a security problem.

Include what is affected, how to reproduce it, and what an attacker could do. We will reply in the report thread.

Only the hosted service at https://boarder.dgit.co and the code in this repository are in scope. Don't test against
other people's accounts or data, and don't run load or denial-of-service tests.
